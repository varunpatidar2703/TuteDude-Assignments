About This Project

This project demonstrates how to create a basic web server using Node.js without Express. The built-in http module receives browser requests and the server decides which HTML page should be returned.

HTTP Module

Creates the server and handles incoming HTTP requests.

Routing

Different URL paths return different HTML pages.

Async Files

HTML and CSS files are loaded asynchronously using fs/promises.
