# Assignment 7 – To-Do List REST API Project

This project is based on the assignment requirements shown in the provided image.

## Objective
Identify and implement the necessary REST APIs for a To-Do List application, covering CRUD operations.

> The assignment says implementation is planned for subsequent classes. This project provides a working reference implementation so the planned endpoints can be tested.

## Tech Stack
- Backend: Node.js + Express
- Frontend: React + Vite
- Data: In-memory array (no database required)
- API format: JSON
- RESTful HTTP methods: GET, POST, PUT, PATCH, DELETE

## Run the project

### 1. Start backend

```bash
cd backend
npm install
npm start
```

Backend runs at:

`http://localhost:5000`

### 2. Start frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend normally runs at:

`http://localhost:5173`

## REST API Endpoints

| Operation | Method | Endpoint |
|---|---|---|
| Get all tasks | GET | `/api/tasks` |
| Get one task | GET | `/api/tasks/:id` |
| Create task | POST | `/api/tasks` |
| Replace task | PUT | `/api/tasks/:id` |
| Update task | PATCH | `/api/tasks/:id` |
| Delete task | DELETE | `/api/tasks/:id` |
| Toggle completion | PATCH | `/api/tasks/:id/toggle` |

## Example create request

```json
POST /api/tasks

{
  "title": "Complete API assignment",
  "description": "Prepare REST API documentation",
  "priority": "high",
  "dueDate": "2026-09-20"
}
```

A unique ID is generated by the backend using `crypto.randomUUID()`.

## CRUD Mapping

- **Create** → POST `/api/tasks`
- **Read** → GET `/api/tasks` and GET `/api/tasks/:id`
- **Update** → PUT/PATCH `/api/tasks/:id`
- **Delete** → DELETE `/api/tasks/:id`

## Important note

The backend stores data in memory. Restarting the server resets the sample tasks. A real production application should use a database such as MongoDB, PostgreSQL, or MySQL.
